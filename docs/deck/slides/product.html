This is the real interface. The island sits at the top of the screen and reports progress even when it's folded away; here it says the file is ready. Open it and you see each agent's step as it happens: the profiler querying Zetaris, the PM's plan, the spec critic, the engineer, QA and the manager. Before anything runs you get the plan in plain steps, QA's checks, a preview of your file after the change and the new totals sheet. Approve, and the approved code runs and hands you the filled spreadsheet and the automation itself. These screens are from the demo file in sample mode; a live run looks the same, with Nemotron through Nightshift named in the header.
