What it’s built with

Runtime

Python 3.11, FastAPI, httpx, openpyxl; a plain-JS chat island

State

SQLite for the World Model and H-MEM; JSONL traces

Data

Zetaris 2.4.3 in local Docker, Lightning REST tables

Models

Meterless Nightshift, NVIDIA Nemotron lanes

Packaging

Docker on python:3.11-slim; sample mode needs no keys

Built with

Claude Code; every line reviewed and tested

The stack is deliberately small. Python 3.11 with FastAPI and httpx; no agent framework, the agents are plain Python we wrote. The World Model and H-MEM persist in SQLite, and traces are JSONL. Zetaris runs locally in Docker and holds the data as Lightning REST tables. Models come through Meterless Nightshift, routed to NVIDIA Nemotron. The app ships as a Docker image, and sample mode runs without any keys. We built it with Claude Code, and the team reviewed and tested all of it.
