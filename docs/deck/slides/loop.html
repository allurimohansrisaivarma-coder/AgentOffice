This is the deepest loop, and the heart of Track 3. The PM ranks the routines the data revealed and writes a structured spec. Before that plan goes anywhere, a Priority Critic checks every claim against what the activity log measured and sends over-claims back. The Engineer writes code from the spec. QA tests it, and every failing case goes back to the Engineer, up to three revisions. The Manager decides behind a rule gate: it cannot approve code that failed QA. Finally a human approves the exact code, bound to its hash. Every arrow on this slide is a logged handoff.
